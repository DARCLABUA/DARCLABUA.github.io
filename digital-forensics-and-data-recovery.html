Digital forensics and data recovery

Preserving, examining and recovering digital evidence and lost data.

What it is

When an incident happens or data goes missing, someone has to work out what happened and get the data back without destroying evidence along the way.

Digital forensics follows careful procedures: make an exact copy of the drive, verify the copy with a hash, work only on the copy and document every step in a chain of custody so the findings hold up. Data recovery uses many of the same tools to bring back deleted or corrupted files.

The process

  1. IdentifyDetermine which devices and data are relevant.
  2. PreserveCreate a forensic image using a write blocker and record its hash.
  3. AnalyzeBuild timelines, recover deleted files and examine system artifacts.
  4. DocumentRecord every action and keep the chain of custody intact.
  5. ReportExplain findings clearly, or hand back the recovered data.

In practice

What it looks like in a real environment

Typical scenarios from organizations across the industry.

Example

A suspected data theft

An investigator images an employee's laptop through a write blocker, then finds records of a USB drive being connected and files deleted shortly afterward.

Example

A failing hard drive

A researcher's drive starts failing. Recovery tools copy everything readable to a healthy disk first, then pull the lost files back from that copy.

Example

Malware that hides in memory

During incident response, a memory capture from a compromised server reveals malicious code that was never written to disk.

Toolbox

Common tools in the industry

  • Autopsy / The Sleuth Kit
  • FTK Imager
  • EnCase
  • Volatility
  • PhotoRec

Examples of widely used options, not an endorsement, and not necessarily what our lab runs.

Key terms

Forensic image
A bit-for-bit copy of a storage device.
Write blocker
Hardware or software that prevents any change to the original evidence.
Hash
A fingerprint of data used to prove a copy is identical to the original.
Chain of custody
The documented record of who handled evidence and when.
