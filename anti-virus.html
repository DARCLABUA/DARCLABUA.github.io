Security stack / Anti-virus

Anti-virus

Software on each computer that detects, blocks and removes malicious code.

What it is

Endpoints, meaning the laptops, desktops and servers people actually use, are where most attacks land: a phishing attachment, a malicious download, an infected USB drive.

Traditional anti-virus compares files against signatures of known malware. Modern endpoint protection adds behavioral detection that flags suspicious actions, like a document trying to launch a command shell. Endpoint detection and response (EDR) goes further, recording activity on each machine so analysts can investigate and isolate a compromised host remotely.

How it works

  1. DeployInstall an agent on every endpoint and confirm each one reports in.
  2. Set policyConfigure real-time protection, scan schedules and any exclusions.
  3. DetectCatch threats by signature, by behavior or by both.
  4. RespondQuarantine the file, kill the process or isolate the machine from the network.
  5. ReviewInvestigate what happened and tune policies to reduce noise.

In practice

What it looks like in a real environment

Typical scenarios from organizations across the industry.

Example

A malicious invoice

An employee opens an emailed invoice that tries to download ransomware. Real-time protection blocks the download and quarantines the attachment before anything runs.

Example

Stopping ransomware mid-attack

EDR notices one workstation rapidly rewriting hundreds of files. An analyst isolates it from the network with one click, containing the damage while they investigate.

Example

Tuning out the noise

A development team's build folder keeps triggering false alarms. IT adds a narrow, documented exclusion instead of turning protection off.

Key terms

Signature
A fingerprint of known malware used to recognize it.
Behavioral detection
Flagging software by what it does rather than what it looks like.
EDR
Endpoint detection and response: recording endpoint activity to detect, investigate and contain threats.
Quarantine
Moving a suspicious file somewhere it can't run.
