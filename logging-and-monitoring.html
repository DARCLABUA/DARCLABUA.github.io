Logging and monitoring

Collecting the records systems produce and watching them for signs of trouble.

What it is

Servers, workstations, firewalls and applications constantly write logs: who signed in, what program ran, what connected to what. Spread across hundreds of machines, those records are impossible to read by hand.

Logging and monitoring pulls them into one place, usually a SIEM, where events from different systems can be correlated. Detection rules raise alerts when a pattern looks like an attack, and the stored history lets a team reconstruct what happened after the fact.

How it works

  1. CollectAgents and log forwarders gather events from servers, endpoints and network devices.
  2. CentralizeLogs land in one system and are normalized so they can be searched together.
  3. DetectCorrelation rules look for suspicious patterns across sources.
  4. TriageAnalysts review alerts, close false positives and escalate real incidents.
  5. RetainLogs are kept long enough to investigate incidents and meet policy requirements.

In practice

What it looks like in a real environment

Typical scenarios from organizations across the industry.

Example

Catching a password-guessing attack

A rule fires when one account has dozens of failed sign-ins within a few minutes followed by a success. An analyst checks where the sign-in came from and locks the account.

Example

Spotting an unexpected change

File integrity monitoring alerts that a configuration file on a web server changed outside any maintenance window, prompting a closer look at who changed it.

Example

Investigating after a breach

Months after an intrusion is discovered, investigators use retained logs to trace how the attacker got in, which systems they touched and what data left the network.

Key terms

SIEM
Security information and event management: the platform that collects, correlates and alerts on logs.
Log source
Any system that sends events to the SIEM.
Correlation rule
Logic that links related events across sources to detect a threat.
False positive
An alert that looks suspicious but turns out to be harmless.
